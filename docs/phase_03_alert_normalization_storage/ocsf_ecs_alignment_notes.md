# OCSF and ECS Alignment Notes

SafeAgentSOC keeps its internal canonical alert schema independent from any single community schema.

This document records alignment intent only:
- OCSF and ECS are useful references
- they are not the runtime contract
- the runtime contract remains SafeAgentSOC-specific

Design intent:
- preserve interoperability
- avoid vendor lock-in
- keep SIEM adapters separate from the canonical model
